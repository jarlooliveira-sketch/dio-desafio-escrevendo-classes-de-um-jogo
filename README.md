# 🎮 Escrevendo as Classes de um Jogo

Desafio da DIO para praticar a criação de classes e objetos em JavaScript.

## 📋 Objetivo

Criar uma classe genérica que represente um herói de uma aventura, contendo:

* Nome
* Idade
* Tipo

O herói possui um método `atacar()` que exibe uma mensagem de acordo com seu tipo.

## ⚔️ Tipos de ataque

| Tipo      | Ataque         |
| --------- | -------------- |
| Mago      | Magia          |
| Guerreiro | Espada         |
| Monge     | Artes marciais |
| Ninja     | Shuriken       |

## 💻 Tecnologias

* JavaScript
* Node.js

## ▶️ Como executar

No terminal, execute:

```bash
node index.js
```

### Exemplo de saída

```text
o mago atacou usando magia
```
